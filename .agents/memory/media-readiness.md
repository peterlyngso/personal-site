---
name: Media readiness
description: Constraint for adding portfolio media without inventing project facts.
---

Optional preview videos, posters, finished-work URLs, and gallery metadata may be represented in the typed content model, but unverified project assets and URLs should remain empty. Use neutral local stills only as representative media.

**Why:** The portfolio must remain factually conservative while its media system is ready for future verified editorial assets.

**How to apply:** When new source media arrives, populate the existing content fields first; do not add placeholder URLs or captions that imply unverified project details.
